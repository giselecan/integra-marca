# Integra Farmácia HRN · marca

Imagens públicas da marca do Integra Farmácia HRN (Hospital Regional Norte): logo, símbolo e, para cada ferramenta,
o favicon e a marca do topo. Só imagens: nenhum dado do hospital, de paciente ou de planilha.

Gerado por `scripts/marca/gerar.mjs --png --publico` no repositório do Integra. Não edite aqui: edite lá e gere de novo.
